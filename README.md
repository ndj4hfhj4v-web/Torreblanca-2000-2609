# Torreblanca 2000 — exportación para GitHub Pages

Sube el contenido de esta carpeta a un repositorio nuevo de GitHub.

En GitHub, abre **Settings → Pages**, selecciona **Deploy from a branch**, elige la rama `main` y la carpeta `/(root)`. Tras guardar, GitHub mostrará la URL pública del juego.

La página de inicio es `index.html`; todos los recursos se sirven con rutas relativas para funcionar desde GitHub Pages.
